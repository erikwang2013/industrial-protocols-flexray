# FlexRay 协议包 — 汽车高速总线，需 FlexRay 控制器桥接

> [English](README.en.md)

FlexRay 汽车高速容错总线协议（10 Mbps）。需要专用 FlexRay 控制器硬件，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-flexray
```

## 功能

FlexRay 静态/动态段桥接、BridgeConnector 连接管理

## 所需硬件

FlexRay 控制器（NXP MFR4310 / E-Ray IP）

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Plain PHP

## 系统要求

- PHP >= 8.1
- FlexRay 控制器硬件
- erikwang2013/industrial-protocols-kernel
